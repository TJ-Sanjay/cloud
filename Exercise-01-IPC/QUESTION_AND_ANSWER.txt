EXERCISE 1 — INTER-PROCESS COMMUNICATION IN DISTRIBUTED COMPUTING
==================================================================

QUESTION
--------
Task 1: Create a socket client and server. The client sends a message containing numbers; the server receives the message, parses the numbers, calculates their sum, and sends the result back.

Task 2: Define a DataObject with name and values attributes. Serialize it with pickle, send it from client to server, deserialize it on the server, calculate the sum of values, and return the sum.

AIM
---
Understand TCP socket communication and Python object serialization.

WHERE TO DO THIS
----------------
Clone this repository on the Ubuntu VM and run:
git clone https://github.com/TJ-Sanjay/cloud.git
cd cloud/Exercise-01-IPC
If you already cloned it, just cd into the existing Exercise-01-IPC folder. Both programs can run in two terminal windows on the same VM. For a two-VM demo, change HOST in the clients to the server VM's private IP and allow TCP ports 12345 and 12346 in the private lab network.

TASK 1 — BASIC NUMBER-SUM SERVER
-------------------------------
Terminal 1 (from this folder):
python3 server_numbers.py

Terminal 2 (from this folder):
python3 client_numbers.py
Enter numbers separated by spaces, for example: 10 20 30
Expected client output: Server response: 60
Type exit to stop the client.

TASK 2 — SERIALIZED OBJECT
--------------------------
Terminal 1:
python3 server_object.py

Terminal 2:
python3 client_object.py
Enter name: Sanjay
Enter integer values separated by spaces: 10 20 30 40
Expected output: Sum returned by server: 100

FILES
-----
- server_numbers.py / client_numbers.py: Task 1
- data_object.py / server_object.py / client_object.py: Task 2

TROUBLESHOOTING
---------------
- Start the server before the client.
- Connection refused: check the server is running and HOST/PORT match.
- Address already in use: stop the old server with Ctrl+C before restarting.
- For two VMs, use the server's private IP, not 127.0.0.1. Check the firewall.

SECURITY
--------
Pickle is unsafe for untrusted data because unpickling may execute arbitrary code. Use this pickle example only with a trusted client on a lab network. Never accept pickle payloads from the public internet.
