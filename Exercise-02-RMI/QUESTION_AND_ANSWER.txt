EXERCISE 2 — REMOTE METHOD INVOCATION (RMI) WITH PYRO4
=======================================================

QUESTION
--------
Create a Calculator service on a server with remote addition and multiplication methods. Expose it with Pyro4, register it with a Pyro4 daemon, and let a client enter the server URI and invoke both methods remotely.

AIM
---
Understand remote method invocation between a client and server process.

WHERE TO DO THIS
----------------
Clone this repository on Ubuntu and enter cloud/Exercise-02-RMI. Run both programs in Ubuntu. They can run on one VM for a basic demo. For two VMs, configure PYRO_HOST to the server's reachable private IP and allow TCP port 50000 in the VM firewall.

SETUP
-----
python3 -m venv .venv
source .venv/bin/activate
python -m pip install --upgrade pip
python -m pip install Pyro4

RUN
---
Same VM: in Terminal 1, run:
source .venv/bin/activate
python server.py

Copy the complete URI printed by the server.

In Terminal 2:
source .venv/bin/activate
python client.py
Paste the URI, then enter two integers.

For separate VMs, run this on the server VM, replacing the IP with its actual private IP:
PYRO_HOST=192.168.56.101 python server.py
Then enter the URI printed by that command on the client VM.

EXPECTED RESULT
---------------
For inputs 8 and 5:
Addition result: 13
Multiplication result: 40

TROUBLESHOOTING
---------------
- Run both programs with the same Pyro4 environment.
- Paste the full URI exactly as printed.
- For separate VMs, the URI must contain the server's reachable private IP, not 127.0.0.1.
- This direct-URI example does not require a Pyro nameserver.
